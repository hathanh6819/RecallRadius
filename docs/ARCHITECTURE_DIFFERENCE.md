# Originality and architecture audit

| Dimension | RecallRadius design |
|---|---|
| Product primitive | Sealed multi-wallet inventory classification batch |
| Lifecycle | Open registration → creator seal → permissionless recurring scope epochs |
| Storage | Cases, independently owned items, append-only epoch records and per-item diagnostics |
| Evidence | One contract-derived FDA advisory, not arbitrary URLs or party-authored evidence |
| Consensus | Validators normalize one bounded source-fact tuple |
| Deterministic effect | Contract intersects UPC/brand/lot/date/state and records status transitions |
| Evolution | New epoch compares scope digest with the prior epoch and preserves history |
| UI | Batch workstation and source-epoch console, not a graph, escrow wizard or policy diff |

Preflight:

- Not a field-renamed clone: yes
- Materially new state machine: yes
- Materially new evidence acquisition: yes
- Materially new consensus binding: yes
- Materially new storage and invariants: yes
- Independent frontend information architecture: yes
- Reviewer-visible independent product primitive: yes
